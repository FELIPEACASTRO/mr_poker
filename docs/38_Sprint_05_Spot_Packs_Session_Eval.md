# Sprint 05 — Spot Packs, Session Eval e Persistência de Traces

## Objetivo
Transformar o projeto em uma plataforma local mais útil para treino e avaliação contínua.

## Entregas
- biblioteca de spot packs
- endpoint para listar packs
- endpoint para instanciar packs
- persistência de decision traces
- persistência de sessions
- endpoint para rodar sessão local
- endpoint para recuperar sessão e traces
- EV proxy local por sessão

## Definição de done
- packs instanciados corretamente
- sessão local gera traces persistidos
- sumário de sessão disponível via API
- testes verdes
