# Sprint 01 — Engine POC

## Objetivo
Entregar um engine heads-up no-limit local, determinístico, testável e reproduzível.

## Escopo entregue
- setup de mão
- blinds heads-up
- dealing
- fluxo pre-flop -> river
- showdown
- replay snapshot
- API local mínima

## Critério de aceite
- testes passando
- replays reproduzíveis
- fold/call/checkdown funcionando
- showdown correto em cenários conhecidos
