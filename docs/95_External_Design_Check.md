# External design check

- OpenSpiel-style evaluation and exploitability-centric lab thinking
- PHH/PHH-like canonical hand-history orientation
- PokerKit-style flexible simulation mindset

The code in this repository is still a **local lab / alpha-track foundation**, not a production-grade poker platform.
